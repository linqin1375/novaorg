# 2026-10-21 改造记录

## 工程修改

1. 原生工具协议：LlmToolCall/LlmMessage 保留 ID、参数和工具结果；文本提到工具不再当作真实后端调用。工具名称在 HTTP 端口转换为安全名称，内部注册名不变。
2. 可选 strict schema；非法参数 JSON 明确失败，不降级成空对象执行。限流/服务端错误允许有界重试；独立付费评测禁用重试。
3. StopReason 与持久化 AgentTurn：预算耗尽、循环熔断、空答复和输出截断不再 DONE；审批会停止同批后续动作。
4. 多订单 A100–A104 与 Flyway V2/V3；查询按实际订单返回履约状态、核算延迟和剩余可退金额；退款余额各自约束；模型不得凭空选择用户未提供的订单。补齐沙箱中未发货取消退款规则，明确本金退款与赔付不是同一金额。
5. customer.clarify 和 /api/tasks/{id}/clarify：申请人补信息，revision 防过期；恢复原步骤，保留历史记录与当前轨迹。
6. embedding 适配器批量请求、按 index 对齐、维度/非数值/零向量检查、有界缓存；不会在 API 出错后悄悄返回哈希向量。
7. 源码默认值统一关闭启发式 rerank；开发/留出集分开，开关消融实际运行。澄清人工特征、Hit@k 与数据来源。
8. 评测区分请求/执行、POLICY/MODEL、检索/回答引用与完成状态；检查沙箱账本，保留失败原因。
9. 新独立 VerificationCli、API 配置、启动/停止/评测/HTTP 验收脚本。密钥和本机登录密码 DPAPI 保存，.local/data/target 不提交。
10. 控制台增加待补充表单和公开执行轨迹，展示指标含义。
11. 规划增加明确的业务 intent，以能力约束选择岗位与工具范围；防止把需要赔付制度和计算器的请求交给无权限客服，原生非法规划明确失败。
12. 引用采用稳定 docId#chunkIndex，主动检索返回结构化证据并合并引用登记；计算任务必须实际调用试算工具，不能只生成一个金额。
13. 待审批评测核对冻结金额；SLA 与业务完成状态分开。Windows 启动改为运行独立 jar 副本，解决服务运行时 target 包被占用的问题。
14. 用户补充 GLM 接口后，接入 embedding-3 / 1024d，补上请求维度参数、供应商 usage 记录；新增仅检索验收模式，不占聊天调用预算，保存 60 条开发查询与 20 条合成留出查询的真实消融。
